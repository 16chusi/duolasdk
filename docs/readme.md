# Duola SDK 核心模块文档

## 概述

欢迎使用 Duola SDK 的核心模块 (`@duolasdk/core`) 文档。

`core` 模块是整个 Duola SDK 的基石，它提供了一系列经过精心设计和封装的基础能力，涵盖了数据存储、人工智能、网络通信、日志记录等多个方面。这些模块旨在为上层应用提供稳定、统一且易于使用的接口，从而加速业务开发。

本文档集合旨在为开发者提供每个核心模块的详细说明、API 参考和最佳实践。

## 模块索引

以下是 `core` 目录下的主要模块文档列表。建议按照顺序阅读，以建立对 SDK 的全面理解。

1.  **[存储模块 (sotre.md)](./sotre.md)**
    -   **简介**: 提供了强大的数据存储层，拥有类似 Redis 的简洁 API 和原生 SQL 的灵活性。支持持久化和内存两种模式。是 SDK 中最核心和最复杂的模块。

2.  **[AI 模块 (ai.md)](./ai.md)**
    -   **简介**: 提供了与大语言模型交互的统一接口。内置了强大的 Ollama 客户端，并包含一个 OpenAI API 兼容适配器，极大地增强了应用的扩展性。

3.  **[网络模块 (net.md)](./net.md)**
    -   **简介**: 一个功能丰富的 HTTP 客户端，设计灵感来源于 `axios`。支持拦截器、Cookie 管理、流式传输和断点续传等高级功能。

4.  **[日志模块 (log.md)](./log.md)**
    -   **简介**: 一个可配置的日志记录工具，支持多种日志级别以及文件和控制台输出，并为 Wails 框架提供了适配器。

5.  **[其他模块 (misc.md)](./misc.md)**
    -   **简介**: 包含了事件、IO、定时任务、操作系统、支付、发布和版本号等其他核心能力的介绍和未来规划。
