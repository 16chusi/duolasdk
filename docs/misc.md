# 其他核心模块

## 概述

`duolasdk/core` 目录下除了 `store`, `ai`, `net`, `log` 等核心模块外，还包含了一些用于未来功能扩展的占位符文件。这些文件目前只定义了模块的预期能力，为 SDK 的后续发展规划了方向。

## 模块简介

-   **`event.go`**
    -   **规划能力**: 全局事件总线。
    -   **预期用途**: 用于实现应用程序内部的解耦通信。不同模块之间可以通过事件总线发布和订阅事件，而无需直接相互依赖。

-   **`io.go`**
    -   **规划能力**: IO 能力支持。
    -   **预期用途**: 封装文件读写、路径操作等 IO 相关的功能，提供比原生 `os` 和 `io` 包更便捷的工具函数。

-   **`job.go`**
    -   **规划能力**: 定时任务。
    -   **预期用途**: 提供一个简单的定时任务调度器，可以用于执行周期性的后台任务，如数据同步、缓存清理等。

-   **`os.go`**
    -   **规划能力**: 操作系统能力支持。
    -   **预期用途**: 封装与操作系统交互的功能，例如获取系统信息、执行系统命令、管理进程等。

-   **`pay.go`**
    -   **规划能力**: 支付能力。
    -   **预期用途**: 集成常见的支付渠道（如微信支付、支付宝），提供统一的支付和订单查询接口。

-   **`publish.go`**
    -   **规划能力**: 打包发布能力。
    -   **预期用途**: 提供自动化打包、签名和发布应用程序到不同平台（如 Windows, macOS, Linux）的工具和脚本。

-   **`version.go`**
    -   **当前功能**: 提供 `Version()` 函数，返回当前 SDK 的硬编码版本号。
